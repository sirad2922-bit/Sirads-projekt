# Sirads Café

Webbplats för ett fiktivt café i Göteborg, gjord i kursen DT224G vid Mittuniversitetet.

**Webbplats:** https://sirad2922-bit.github.io/Sirads-projekt/

## Innehåll

Fyra sidor: Start, Meny, Om oss och Kontakt.

## Tekniker

- HTML, CSS och JavaScript
- Responsiv design (mobile first) med Grid och Flexbox
- Mobilmeny och formulärvalidering med JavaScript

## Mappar

- `css/` – stilmall
- `js/` – JavaScript
- `Img/` – bilder
- `design/` – wireframes och mockup
- `rapport/` – rapport i PDF
